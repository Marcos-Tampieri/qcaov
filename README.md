# QCAdesigner Online Viewer
First you will need to clone https://github.com/amagus/QCADesigner repository and run the update.sh script in the script/ folder to create the custom source code, which makes this web interface runable.
```bash
git clone https://github.com/Marcos-Tampieri/qcaov.git
cd qcaov/backend/
python3 server.py
```
